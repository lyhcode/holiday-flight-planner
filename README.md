# Holiday Flight Planner｜連假彈性旅遊規劃

支援自由行與跟團的 Agent Skill：整合官方連假研究、彈性日期、機票或出團梯次比價、請假成本與旅遊報告。技能名稱仍為 `holiday-flight-planner`，原有安裝與呼叫方式不變。

## 安裝

需先具備 Node.js 與 npm／npx。使用 [Skills CLI](https://github.com/vercel-labs/skills) 安裝到 Codex：

```sh
npx skills add lyhcode/holiday-flight-planner --skill holiday-flight-planner -g -a codex
```

若要互動選擇其他支援的 agent：

```sh
npx skills add lyhcode/holiday-flight-planner
```

也可下載 repository ZIP，將包含 `SKILL.md`、`agents/`、`references/` 的資料夾命名為 `holiday-flight-planner`，放進 Codex 技能目錄 `~/.codex/skills/`。若設定了 `CODEX_HOME`，使用其下的 `skills/`。請避免將同一技能重複安裝到多個位置。

## 使用範例

```text
使用 $holiday-flight-planner，找 2027 年上半年台灣連假，
台北飛大阪玩 4～5 天，去回日期可各前後調整 3 天，
最多請假 2 天，最後做成 PDF 報告。
```

跟團使用範例：

```text
使用 $holiday-flight-planner，以跟團為主找連假附近的沖繩 4～5 日團。
2 位成人同住雙人房，每人預算 3 萬元，最多請假 2 天，
不接受購物站，優先已成團，請比較已知必要總費用與行程品質。
```

跟團模式查旅行社的實際梯次，分開列出名額與成團狀態，核對房型、必要費用、購物站、自費活動及暫定航班／飯店。也可明確要求跟團與自由行比較；將對齊住宿、交通、餐食及門票等費用口徑。

其他情境：

- 「幫我比較清明連假附近的機票，要含托運行李。」
- 「最多只請一天假，幫我重排剛才的方案。」
- 「加一點預算能不能晚一點回來，多玩半天？」
- 「把剛才的查詢結果做成可分享的報告。」

## 工作流程

1. 確認路線、旅行期間、人數、天數、工作週與日期彈性。
2. 查核官方假日與補假，區分自然連假及自行請假串接。
3. 自由行比較日期組合；跟團比較實際出團梯次，計算請假與可比較的費用。
4. 自由行核對去回程；跟團核對名額、成團狀態、房型、必要費用及每日行程。
5. 提出最低價、少請假、較好航班時間等有價值的方案。
6. 依需求製作包含查詢日期、證據層級與來源連結的報告。

預設 4～5 天、連假附近日期可調整 1～3 天；自由行可暫用 1 成人經濟艙、優先直飛。跟團須按實際梯次日期，依人數、年齡與房型核算費用，不能自行移動回程。使用者可調整條件。目的地、年份、幣別與假日管轄區不限台灣或日本。

## 環境需求與範圍

這是給 AI agent 的流程指引，不是獨立爬蟲或訂票程式。使用端需提供網路研究及可用的瀏覽器操作工具；Google 機票互動操作可依環境使用 agent-browser 或其他瀏覽器工具。製作 PDF 另需可用的文件工具與中文字體，相關工具不隨此套件安裝。

自由行區分日期網格估價、已核對去回程及已查看出票頁；跟團區分廣告價、梯次適用報價、名額與成團證據，並標示資料時間。它不自動購票、付款或設定價格監控。
