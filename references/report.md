# 旅遊決策報告

沿用本次已核實資料，不把舊價格改標為新的查詢日期。篇幅依結果數量調整，避免為湊頁數加入空泛旅遊內容。

## 建議內容

1. **條件與優先建議**：旅行範圍、路線、4／5 天等實際條件、查詢時間。推薦最低價與較均衡方案，寫出請假及遊玩時間的理由。
2. **假期比較總覽**：假期名稱／放假區間、基準日期／價格、彈性日期／價格、天數／夜數、請假、節省。可將欄位拆成兩表以維持可讀性。
3. **已核對航班**：去回日期、航空、機場、當地起降時間、回程跨日及分段購票；附可點擊的查詢連結。
4. **有價值的替代方案**：多玩一天、少請一天假、加價換晚回等。網格估價與已核對航班明確區分。
5. **方法與來源**：假日官方來源、位移範圍、工作週假設、幣別與行李口徑、未查核部分。只對機票比較的節省額，不延伸宣稱整趟旅費同幅下降。

## 品質檢查

- 節省額 = 基準來回價 - 候選來回價；百分比使用基準作分母。不同天數有標示，請假日期可追溯。
- 每個主要候選確實符合長度、位移與假期重疊條件。並列不符合條件的方案時明示例外。
- 來源與價格證據層級對得上；未重新查詢不寫「最新票價」。
- 報告不寫死使用者姓名、目的地、年份、範例票價或任何上一份報告的本機路徑。
- PDF 使用可呈現繁體中文的字體，檢查每頁渲染，避免表格切斷、孤立註解、空白頁與不可讀的小字。保留可點擊連結。
- 結尾交付可下載檔案；可用預覽工具時展示報告。若工具不足，交付 Markdown 報告並明示格式限制，不宣稱已產生 PDF。

## 可接受的使用示例

- 「找明年上半年台灣連假，台北飛大阪玩五天，前後三天可以調整。」→ 確認年度，研究官方假期、比價與核對候選。
- 「最多只請一天假，幫我重排剛才的方案。」→ 重算既有候選，必要時擴查；不沿用三天假的最低价作推薦。
- 「把剛才結果做成報告。」→ 使用既有研究時間與證據，產出報告，無須重做所有比價。
