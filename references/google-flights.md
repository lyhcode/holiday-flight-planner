# Google 機票操作與證據

## 工具與狀態

- 先讀所用瀏覽器工具的即時操作文件。重用與任務相關的現有分頁；遵守使用者指定的瀏覽器。工具不可用時可改用可取得的網頁資料，但要揭露無法完成互動式比價的限制。
- 在修改日期前確認來回、乘客、艙等、機場、幣別與直飛篩選。城市可能包含多個機場，最終結果記錄實際機場。
- 元素索引、選擇器與日期網格來自當下可見頁面，不重用舊索引，也不複製先前任務的瀏覽器綁定或 tfs 編碼。
- 日期輸入後核對完成按鈕或表單實際顯示的年份與去回日期。提交後先前航班可能暫留；等候並重新讀取狀態，確認結果日期一致再擷取價格。
- 網格通常以基準日期展示去回各七天。依實際可見範圍記錄，等待價格載入完成；載入中或空白不是免費或售罄的證據。
- 系統錯誤可使用頁面提供的重新載入並重新確認篩選。若同一操作有限重試仍失敗，停止重複動作，改走可用查詢路徑或標記未驗證。

## 證據紀錄

逐組保留下列資訊，格式可依工具選擇 JSON、表格或 Markdown：

| 資料 | 應包含內容 |
|---|---|
| 查詢條件 | 查詢日期／時區、乘客、艙等、幣別、機場範圍、轉機與行李條件 |
| 假期 | 官方放假起訖、官方來源網址、公告或推算狀態 |
| 基準 | 去回日期、含首尾天數、請假日期、來回價格 |
| 候選 | 去回日期、相對基準位移、天數、請假日期、價格、證據層級 |
| 航班 | 去回航空、實際機場、當地起降日期時間、隔日標記、轉機、分段購票 |
| 來源 | 實際取得的搜尋頁網址、必要的頁面文字或截图 |

不要從去程航空推斷來回皆為同一家；最低價可能是混搭單程票。只把有足夠資料支持的數字寫入節省金額或價格百分比。相同最低價可優先選少請假或較好時間者，並說明取捨。

價錢超出航空開放預訂期間時，記錄未開放或頁面實際狀態；不能推論該航空永久不飛。不要以搜尋結果中的泛用路線「最低價起」替代指定日期查詢。

完成後可保留最有用的查詢分頁，依工具的保留／交付機制操作；不要更改使用者其他無關分頁。
